## 1. גבולות המסע (Scope)

| | |
|---|---|
| **התחלה** | נועה הסתכלה על האינסטגרם שלה אתמול וחשבה "אין לי מושג מה אני מעלה השבוע." |
| **סוף** | נועה סיימה שבוע שבו פרסמה 5 פוסטים בזמנים שתכננה — ופותחת את השבוע הבא בכלי. |
| **תרחיש** | נועה מקדישה "שעת תוכן" יום ראשון בערב לתכנון השבוע. בשאר השבוע היא רק *מבצעת* (פותחת את הפוסט של היום ומעלה). |
| **משך** | שבוע מלא — לא session בודד. |

**למה גבולות אלה:** ה-feature עובד אם נועה חוזרת אליו **שבוע שני ברציפות**. לא מספיק שהיא תזמנה — חייב לבנות את הרגל ההישנות.

### 📅 שלב 4 — Scheduling (`/calendar`)

| שדה | תוכן |
|---|---|
| **מטרה** | לפזר 4–6 פוסטים על השבוע בצורה אסטרטגית |
| **פעולות** | מגיעה ל-`/calendar` (דרך CTA או ניווט). רואה פאנל תור משמאל + grid שבועי 7 טורים. גוררת פוסט מהפאנל אל יום ספציפי. עוברת לשבוע הבא, ממשיכה. |
| **טאצ'פוינטים** | `/calendar` page, drag-and-drop (HTML5 native), week navigation |
| **חושבת** | "יום שני בבוקר → תוכן אוטוריטטיבי. רביעי → carousel חינוכי. חמישי → סטורי קליל. שבת — לא מעלה." |
| **שואלת** | "מתי הקהל שלי הכי אקטיבי? איך אני יודעת אם פיזרתי טוב?" |
| **רגש** | 😄 +2 (הרגע הכי חיובי במסע — שליטה + ראייה אסטרטגית) |
| **כאב** | (1) Empty state של פאנל ריק — היא לא יודעת איך פוסטים מגיעים אליו. (2) Drag feedback לא ברור = ספק = נטישה. (3) שבוע עם 1 פוסט מתוזמן ו-6 ריקים = "אני לא מספיק" — anxiety pattern. |
| **הזדמנות** ⭐ | (1) Empty state בפאנל עם הוראה: "פתחו פוסט ב-'פוסטי ליבה' ולחצו 'תזמנו'." (2) Drag-over: ring צהוב + hover surface. (3) **לא** להציג counter תאים ריקים — להציג רק מה ש**יש**, לא מה ש**אין**. |

**MoT-3:** ה-drag feedback של drop zone — רגע אמת ויזואלי שקובע אמון בכלי.

### 🚀 שלב 5 — Execution (יום הפרסום)

| שדה | תוכן |
|---|---|
| **מטרה** | להעלות את הפוסט של היום במהירות, בלי לחפש מידע |
| **פעולות** | יום שלישי 8:30, פותחת `/calendar`. רואה chip צהוב על "היום." לוחצת → Sheet נפתח. **מעתיקה** סקריפט לאינסטגרם. **מורידה** מדיה מ-Drive (לחיצה על Link2 icon). **מעתיקה** מילת טריגר ושמה במאניצ'אט. מסמנת ✓ "פורסם." |
| **טאצ'פוינטים** | `/calendar`, Sheet, Google Drive (טאב חדש), Instagram/IG Studio, ManyChat |
| **חושבת** | "הכל פה. אני לא צריכה לפתוח עוד טאבים." |
| **שואלת** | "האם סימנתי שפרסמתי? אני אזכור עוד יומיים?" |
| **רגש** | 😄 +2 (סגירת לולאה — מ"רעיון" ל"פרסום" בכלי אחד) |
| **כאב** | (1) אם אין state "פורסם" — נועה תתבלבל בעוד שבועיים אם פרסמה או לא. (2) מילת טריגר לא copy-able בקליק → אנגרה. |
| **הזדמנות** ⭐ | (1) **Checkbox "פורסם" על ה-chip** → opacity 60% + ✓ + תאריך. (2) כפתור Copy ליד מילת הטריגר. (3) הצגה בולטת של "מה היום" כשהיא נכנסת ב-9 בבוקר. |

**MoT-4:** סימון "פורסם" — הגשר בין "תזמנתי" ל"באמת קרה." בלעדיו, נועה תאבד אמון תוך שבועיים.

**MoT-5:** הרגע שהיא חוזרת בשבוע השני. אם השבוע הראשון לא נתן לה תחושת הישג — לא תחזור.
